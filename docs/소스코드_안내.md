# 실행 소스 코드 안내

> 대회 제출 항목 '실행 소스 코드': Agent 실행 코드, Prompt, Tool/API 연동 및 데이터 처리 코드, 사용 모델·라이브러리 정보

## 1. Agent 실행 코드

| 파일 | 역할 |
|---|---|
| [app/agent/loop.py](../app/agent/loop.py) | **Agent 루프.** Claude에 도구 목록과 대화를 보내고, 도구 호출 → 실행 → 결과 전달을 답이 끝날 때까지 반복. 토큰·비용 기록, 키 오류·크레딧 오류 처리 |
| [app/api/main.py](../app/api/main.py) | FastAPI 서버. `POST /api/chat`(대화, SSE 스트리밍), 화면용 데이터 API, 하루 사용 한도·접속 코드 |
| [scripts/chat.py](../scripts/chat.py) | 터미널에서 Agent와 대화 (`--mode owner` / `--mode tourist`) |

## 2. Prompt

| 파일 | 내용 |
|---|---|
| [app/agent/prompts.py](../app/agent/prompts.py) | 시스템 프롬프트. 공통 규칙(근거 표기, 정확한 용어 + 괄호 풀이, 내부 번호 숨기기, 모르면 묻기) + 사장님 절차(가게 확인 → 네이버 → 분석 → 초안 → 승인) + 관광객 절차(추천·혼잡·일정) |

## 6. 사용 모델

| 역할 | 모델 | 제공 | 설정 |
|---|---|---|---|
| Agent (사장님) | `claude-sonnet-5-5` | Anthropic API | `CLAUDE_MODEL_OWNER` |
| Agent (관광객) | `claude-haiku-5-5` | Anthropic API | `CLAUDE_MODEL_TOURIST` |
| 메뉴판 사진 읽기 | 위 Claude 모델의 이미지 입력 | Anthropic API | — |
| 홍보 배경 이미지 | Gemini 이미지 생성 모델 | Google API | `GEMINI_IMAGE_MODEL`, 하루 `GEMINI_DAILY_LIMIT`장 |
| 방문 수요 예측 | HistGradientBoostingRegressor | scikit-learn, 직접 학습 | `data/processed/demand_model.joblib` |
| 리뷰 감성 | KoELECTRA (Apache-2.0) | Hugging Face 오픈소스 | 미리 계산, `review_sentiment_meta.json` |

## 7. 라이브러리

- 서버 실행: [requirements.txt](../requirements.txt) (최소 버전), [requirements-lock.txt](../requirements-lock.txt) (**테스트한 고정 버전, 평가용 권장**)

- Python 3.11.9, 웹 렌더링용 Chromium (`python -m playwright install chromium`)
